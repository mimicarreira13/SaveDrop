# SaveDrop 💧

A mobile prototype that promotes water saving through persuasive computing, gamification and eco-feedback.

**Live demo:** https://savedrop.onrender.com
> Note: the app may take a while to load, since it runs on free hosting.

---

## 🎯 About

Many people use more water than they realise, mainly because they get no immediate feedback on their habits. SaveDrop makes water saving visible: users log their daily activities, set savings goals and earn symbolic rewards for their progress.

## ✨ Features

- **Onboarding questionnaire:** three short questions about everyday habits, used to build a baseline estimate of consumption
- **Dashboard:** litres saved compared with the goal, a daily savings streak and quick tips
- **Log activity:** activities grouped by category (personal hygiene, kitchen and taps, laundry, outdoor), each with an estimated saving
- **Goals:** active goals with progress, monthly history and different goal types
- **Mascot (Splashy):** reacts to the user's progress, from happy to worried
- **Rewards:** levels, badges and a daily bonus for consistent logging
- **Ranking:** current position, a podium and weekly challenges

## 🧠 Persuasive Strategies

- **Eco-feedback:** immediate, visual feedback that turns litres into everyday equivalents
- **Gamification:** levels, badges and a mascot that reinforce positive behaviour
- **Personalisation:** goals and feedback adjusted to the answers given during onboarding
- **Social comparison:** a friendly ranking, designed so that personal progress is always valued

The design is based on the Fogg Behavior Model and the Persuasive Systems Design framework.

## 🧪 Evaluation

The prototype was tested with 6 participants, aged 18 to 70. Feedback on ease of use and motivation was mostly positive, and even the participants who were initially less interested said the mascot and the ranking would keep them using the app.

This was a small academic study, so the results are an early indication rather than a conclusion.

## 🚀 Running Locally

1. Open a terminal in the project root (where `package.json` is).
2. Install dependencies:
   ```bash
   npm install
   ```
3. Build the project:
   ```bash
   npm run build
   ```
4. Start the application:
   ```bash
   npm run start
   ```
5. Open `http://localhost:3000` in your browser.

> Note: using the live demo is the easiest way to try the app. Running it locally is mainly for exploring the code.
